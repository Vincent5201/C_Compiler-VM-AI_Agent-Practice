# C Compiler Practice

This repository is dedicated to practicing C compiler development and exploring integrations with the Gemini CLI.

## Overview

The primary goals of this project are:
- To practice building a C compiler from scratch (lexing, parsing, code generation, etc.).
- To experiment with and utilize **Gemini CLI** features, workflows, and custom subagents in software engineering.

## Project Structure

- `GEMIN.md`: Custom instructions and guidelines for Gemini CLI interactions in this repository.
- `README.md`: Project overview and documentation.
